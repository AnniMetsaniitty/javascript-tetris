# Compton Line Legacy

A classic Tetris-inspired desktop game built with JavaScript and Electron.

## Features

- Classic falling block gameplay
- Keyboard controls
- Score tracking
- Desktop application experience

## Technologies

- HTML
- CSS
- JavaScript
- Electron

## Running the Application

Clone the repository:

```bash
git clone https://github.com/AnniMetsaniitty/javascript-tetris.git
```

Navigate to the project folder:

```bash
cd javascript-tetris
```

Install dependencies:

```bash
npm install
```

Start the application:

```bash
npm start
```
